# The Vending Machine Pickup Line

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Node](https://img.shields.io/badge/Node-22-green)](https://nodejs.org/)

One pickup line, as if a vending machine were flirting with a passing human.
The program writes the line exactly to `/output/entry.txt` (87 characters,
well under the 200-character limit).

> Press B4 all you want, but you’re the only snack around here getting stuck in my coils.

Run it with Node 22: `node main.ts`
