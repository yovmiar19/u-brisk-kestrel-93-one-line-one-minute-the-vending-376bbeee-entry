One pickup line, as if a vending machine were flirting with a passing human.
B4 is the machine's own button, and the passer-by is the snack that never
drops free from its coils. The program writes the line exactly to
`/output/entry.txt` (87 characters, well under the 200-character limit).

> Press B4 all you want, but you’re the only snack around here getting stuck in my coils.

Run it with Node 22: `node main.ts`
